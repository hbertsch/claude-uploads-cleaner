## [1.0.0] - 2026-11-02

### Added

- Button on Settings > Privacy > Uploaded files that deletes all uploaded files, in any interface language.
- Inline second confirmation instead of a native dialog.
- Live progress with count, elapsed time and files per second, and a Stop button.
- Retries with backoff for failed deletions and a clear message when claude.ai refuses.
- Message and no deletion when the page layout is not recognised.
- Packages for Chrome, Brave and Edge, and for Firefox.
